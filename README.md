# 📚 Estudos em C# com .NET 8

Este repositório contém anotações, códigos e exemplos práticos das minhas aulas e estudos de C# utilizando a plataforma .NET 8. Cada aula é focada em um conceito específico da linguagem, ideal para iniciantes que desejam aprender de forma progressiva e prática.

## 🧠 Conteúdo das Aulas

| Aula | Tópico | Descrição |
|------|--------|-----------|
| aula00 | Configuração de Ambiente e Hello World | Instalação do .NET 8 e criação do primeiro programa. |
| aula01 | Sintaxe Básica | Estrutura do código, namespaces, classes e métodos. |
| aula02 | Variáveis | Tipos de dados, declaração e inicialização de variáveis. |
| aula03 | Constantes | Diferença entre variáveis e constantes, uso prático. |
| aula04 | Input e Output | Leitura de dados do usuário e exibição de informações no console. |
| aula05 | Operadores Aritméticos | Construção de uma calculadora básica com as quatro operações. |
| aula06 | Estrutura Condicional | Uso do `if` e `else` para decisões no código. |
| aula07 | Operadores de Atribuição | Operadores como `+=`, `-=`, `*=`, etc. |
| aula08 | Operadores Relacionais | Comparações entre valores (`>`, `<`, `==`, `!=`, etc). |
| aula09 | Operadores Lógicos | Operadores `&&`, `||`, `!` e suas aplicações. |
| aula10 | Calculadora com If, Else If, Else e While | Versão mais completa da calculadora com laço de repetição e múltiplas condições. |
